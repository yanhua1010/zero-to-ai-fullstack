向量距离三兄弟

拖动滑块，实时感受欧氏距离、余弦距离、内积的差异

<->

欧氏距离（L2）

两点之间直线距离

B 幅度
dist = √ Σ(aᵢ - bᵢ)²
关注：位置差异（绝对坐标）
核心：两向量端点的空间距离。
长度 & 方向都影响结果。
适用：图像像素差异、地理坐标距离
<=>

余弦距离

只看方向，无视长度

夹角
cos_sim = (A·B) / (|A||B|)
cos_dist = 1 - cos_sim
关注：方向差异（夹角）
核心：两向量夹角的余弦值。
长度缩放不影响结果。
适用：文本语义相似度（TF-IDF / Embedding）
<#>

内积（Dot Product）

方向 + 长度都算分

B 方向
dot = Σ aᵢ·bᵢ = |A||B|cosθ
关注：方向 × 幅度（综合）
核心：夹角越小、长度越大，得分越高。
pgvector 用 负内积 排序（因为越大越好）。
适用：推荐系统、归一化向量场景

场景对比：同一批向量，三种距离给出不同答案

场景 A：长度差异大，方向相同

余弦最靠谱

A = [1, 1]，B = [10, 10]
方向完全相同（夹角=0°）

欧氏：dist ≈ 12.7 → 认为很远 ❌
余弦：dist = 0 → 完全相同 ✅
内积：= 20 → 高分 ✅

场景 B：长度相同，方向不同

三者结论一致

A = [1, 0]，B = [0, 1]
夹角 = 90°，长度都为 1

欧氏：dist = √2 ≈ 1.41
余弦：dist = 1（cos90°=0）
内积：= 0（正交，无关）

场景 C：归一化向量

三者等价

所有向量 |v| = 1（单位向量）
归一化后 L2² = 2(1−cosθ)

欧氏、余弦、内积排序结果
完全一致 ✅
